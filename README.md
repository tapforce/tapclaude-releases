# TapClaude

A macOS menu bar app that shows which Claude Code sessions need you, and lets you answer permission requests and questions without switching windows.

**[Download the latest version →](https://github.com/tapforce/tapclaude-releases/releases/latest)**

Open the `.dmg` and drag TapClaude to Applications. Needs macOS 26 or later. The app updates itself.

This repo only hosts downloads and the update feed. The source code is private.
